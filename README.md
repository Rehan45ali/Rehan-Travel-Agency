Modern static website for **Rehan Travel Agency** by Rehan Ali.

- Email: `rehantravelagency2026@gmail.com`
- Instagram: `https://www.instagram.com/rehantravelagency?igsh=OTFxa2ZycGQyNW1j`

## Website Features

- Responsive landing page for desktop and mobile
- Real travel photo sections for flights, hotels, holidays, bus tickets, and train tickets
- Service cards with clear transport symbols
- Clickable phone, email, WhatsApp, and Instagram links
- Custom logo, favicon, and brand colors
- Removed the old `Travel Styles` and `Why Rehan Travel Agency` sections
- Removed `Visa Services` from the service list

## Main Services

- Flight Booking
- Hotel Reservations
- Holiday Packages
- Bus Tickets
- Train Tickets

## Project Files

- `index.html` contains the website structure and contact links.
- `styles.css` contains the responsive layout, photo styling, and brand design.
- `script.js` controls the mobile menu and reveal animations.
- `assets/` contains the logo, favicon, and brand graphics.
- `scripts/generate_brand_assets.py` regenerates logo and favicon assets.

## Run Locally

Open `index.html` directly in a browser, or run a local server:

```powershell
python -m http.server 4173 --bind 127.0.0.1
```

Then visit:

```text
http://127.0.0.1:4173
```

## Deployment

This project is ready for static hosting on Vercel, Netlify, GitHub Pages, or any standard static web host.
